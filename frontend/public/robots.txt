# Every route renders client-side behind a login, so a crawler only ever sees

# Crawling is deliberately still allowed: de-indexing is driven by the

# act on that tag if it is allowed to fetch the page. Blocking here instead
# would leave any already-indexed URL stuck in the index, because the crawler
# would never see the noindex directive.
#
# Public/marketing content lives on https://spendifyapp.com.
